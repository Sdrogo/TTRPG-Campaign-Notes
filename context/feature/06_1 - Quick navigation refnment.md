## Design

- as implemented right now, the popup for Mention filter for TAG, but doesen't allow to add a Tag as Mention.
- We want to allow to add a Tag Mention in such a way that, when clicking it, lead to a list of all Documents that share that specific TAG
- We also want to allow the creation of a TAG or a new blank Document (only name populated) when no match is found in the popup list. some kind of switch will allow to set the new Entry as a TAG or a Document.


## Implementation

- Everithing should be as Modular and Reusable as Possible.
- Tests for the feature are part of the effort.

## Check When Done

- feature is fully implemented
- all test passes.
- `npm run build` passes.
